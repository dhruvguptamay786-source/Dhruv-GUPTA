ElevenLabs API Configuration

Secure server-side API key configuration

1

Obtain an ElevenLabs API Key

Visit elevenlabs.io, sign in or sign up, click your profile icon in the bottom-left, select API Keys, and click Create API Key.

2

Add Key to .env in Project Root

Open the .env file in the project folder and paste your key:

ELEVENLABS_API_KEY=your_actual_api_key_here

Security: The API key stays securely in your server backend and is never sent to the browser or stored in client code.

3

Restart the Backend Server

In your terminal, restart the server with:

npm start

Then refresh this page. Your live voices and custom cloned voices will load automatically!
